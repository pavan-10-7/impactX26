# ImpactX 26 Website

Official website for **ImpactX 26**, a premier 24-Hour National Level Offline Hackathon presented by IEEE Computer Society RNSIT and the Department of CSE (Cyber Security).

This website serves as the central hub for hackathon registrations, event timelines, themes, team information, and previous event galleries.

## 🚀 Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (v4)
- **Animations:** Motion (Framer Motion)
- **UI Components:** Radix UI primitives & custom Glassmorphism components
- **Icons:** Lucide React
- **Routing:** React Router v7

## 💻 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need Node.js and npm installed on your machine.
- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository to your local machine:
   ```bash
   git clone <repository-url>
   ```

2. Navigate into the project directory:
   ```bash
   cd "ImpactX '26/Website"
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```
   *(Note: The project uses standard `npm`. Ensure you don't delete the `package-lock.json` if it exists.)*

### Running the Development Server

To start the local development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

The application will typically be available at `http://localhost:5173`.

### Building for Production

To create a production-ready build:

```bash
npm run build
```

The optimized static files will be generated in the `dist` folder, ready to be deployed to platforms like Netlify, Vercel, or GitHub Pages.

## 📁 Key Project Structure

- `src/app/pages/`: Contains the main route pages (`Home.tsx`, `Events.tsx`, `Team.tsx`).
- `src/app/components/`: Reusable UI components and section-specific layouts.
- `src/styles/`: Global styles and Tailwind configuration.
- `public/`: Static assets including images (e.g., event gallery pictures) and videos (e.g., `hero.webm`).

## ✨ Features

- **Cinematic Hero Section:** High-performance, scroll-scrubbing WebM background animation.
- **Dynamic Glassmorphism:** Deep backdrop blurs, subtle glows, and optical UI alignment for a premium feel.
- **Interactive Galleries:** 3D Coverflow gallery for browsing past event photos.
- **Responsive Design:** Fully optimized for both desktop and mobile devices.
